## 这次修掉的问题

### 1. 恢复出厂设置缺失

问题：

- 软件没有“清空本机数据并重新开始”的入口
- 一旦本地配置、数据库、备份混乱，普通用户很难自行恢复

处理：

- 在设置页加入“恢复出厂设置”
- 需要输入当前管理员密码
- 需要二次确认
- 执行时清空本机配置、数据库、备份，并自动重启程序

结果：

- 用户可以在软件内完成重置
- 不需要手动删文件

### 2. 首次安装继承旧数据

问题：

- 程序第一次运行时，曾经会把程序目录里的 `config.json`、`monitor.db`、`backups` 复制到 `ProgramData`
- 这会导致“新安装看起来不是新的”

处理：

- 删除这套复制逻辑
- 数据目录现在只负责创建，不再偷偷搬旧数据

结果：

- 新安装默认是空数据
- 安装结果和用户预期一致

### 3. Web 密码明文保存

问题：

- Web 访问密码原来可能以明文形式保存在配置里
- 这不符合基本安全要求

处理：

- Web 密码改成哈希保存
- 老配置如果有非默认明文密码，首次加载时自动迁移成哈希
- 设置页、接口校验统一改成哈希校验

结果：

- 配置文件不再需要保存 Web 密码明文
- 风险明显下降
